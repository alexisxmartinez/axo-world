The useful finding

An expressive portfolio needs two equally considered experiences: a memorable place to explore, and a clear way to understand the work. AXO’s town can provide the first. A readable project guide, direct navigation, and useful takeaways provide the second.

Original implementation blueprint

The following describes AXO’s own architecture. It is a proposed and implemented synthesis, not recovered code from the references.

Journey state

Document scroll selects a continuous route. Explicit navigation chooses one destination and uses the shortest angular path.

Living scene

The camera and AXO’s track position stay fixed. The town rotates; articulated gait, flowers, and water respond locally.

Reading layer

Semantic HTML owns the index, case studies, comparison, and briefs. It remains usable if WebGL is unavailable.

Scroll and direct travel

progress = piecewiseMap(scrollY, measuredChapterAnchors)
townAngle = -2π × progress + manualRotationOffset

onDestination(id):
    target = angleFor(id)
    delta = atan2(sin(target - townAngle), cos(target - townAngle))
    animate townAngle to townAngle + delta
    move document scroll directly to the matching chapter
    cancel the transition if a different scroll input takes over

Gait and arrival

distance = abs(currentAngle - previousAngle) × trackRadius
stepPhase += distance / strideLength
walkStrength eases toward speed derived from recent travel
alternate foot stance and swing; counter-swing arms
keep body bob small; let the tail trail the turn

while traveling: face the tangent in the direction of travel
when settled at a stop: turn inward toward the selected building
with reduced motion: use a stable pose and direct state changes

Environment interactions

project known world interaction anchors into screen space
resolve nearby flowers, canal surface, mascot, and building targets
brush a flower → bend and bloom; tap water → reuse a ripple from a pool
mark successful scene hits so the background does not also react

stars use a separate transparent 2D canvas
nearby pointer movement reveals a small constellation
star tap or keyboard action emits a bounded shooting star
cap DPR and particle counts; pause when hidden or motion is disabled

This approach keeps the downloadable build dependency-free. It does not require adding all the libraries found in another portfolio. A future move to a full 3D engine should be driven by concrete needs such as imported skeletal animation, sophisticated water shaders, or authored model assets.
